# Anthropic & Claude News

Survey recent Anthropic announcements and Claude updates, then provide a concise summary.

## Sources to Check

Use WebSearch and WebFetch to check these sources:

1. **Anthropic Blog** — https://www.anthropic.com/news
2. **Anthropic Research** — https://www.anthropic.com/research
3. **Claude Documentation** — https://docs.anthropic.com (changelog, new features)
4. **Web search** — "Anthropic Claude" news from the past 48 hours

## Output Format

```
## Anthropic Updates — [DATE]

### New Announcements
- [Bullet points of any new blog posts, product announcements]

### Documentation Changes
- [Notable docs updates, new features, deprecations]

### Community/News
- [Relevant third-party coverage, if significant]

### Nothing New
- If no updates found, state "No new updates since last check."
```

Keep it concise. Lead with the most impactful items.
